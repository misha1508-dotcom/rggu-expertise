# Презентация БИОПРАЙМ

3 вертикальные страницы A4 → `bioprime.pdf`. Формат — «глянуть за минуту»:
одно крупное изображение во всю ширину листа, заголовок и три числа на странице.

1. **Продукт** — фото партии, пачка 6 × 250 мл за 1250 ₽, доза 1×10⁶ КОЕ, маржа 75 %,
   полоса со спросом (×16) и лидерами мнений.
2. **Точка продаж** — нарисованная модель холодильника и реальное фото точки,
   675 тыс. ₽ выручки и 447 тыс. ₽ прибыли в месяц, выдача в три шага.
3. **Масштаб** — карта Москвы на 50 точек, 20–25 млн ₽/мес, оценка 1 млрд ₽.

## Пересборка

```bash
python3 build.py     # bioprime.html + bioprime.pdf (headless Chromium)
```

Цифры правятся в HTML-шаблоне внутри `build.py`, динамика спроса — в `TREND_WORLD` / `TREND_RU`.
Шрифт Manrope лежит в `fonts/`, фотографии — в `assets/`.
