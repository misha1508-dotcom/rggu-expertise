# Презентация БИОПРАЙМ

3 вертикальные страницы A4 → `bioprime.pdf`.

1. **Продукт и спрос** — L. reuteri, динамика поискового интереса, лидеры мнений, курс 1250 ₽ за пачку 6 × 250 мл.
2. **Единица масштабирования** — брендированный холодильник с камерой, система выдачи, юнит-экономика точки (18 пачек в день → ≈ 447 тыс. ₽/мес, маржа 75 %).
3. **Масштабирование** — карта Москвы на 50 точек, 20–25 млн ₽/мес, оценка 1 млрд ₽.

## Пересборка

```bash
python3 build.py     # bioprime.html + bioprime.pdf (headless Chromium)
```

Все цифры собраны в начале `build.py` и в HTML-шаблоне внутри него:
динамика спроса — `TREND_WORLD` / `TREND_RU`, юнит-экономика и цели по сети — в тексте страниц 2 и 3.

Шрифт Manrope лежит локально в `fonts/`, фотографии — в `assets/` (обрезанные и сжатые версии).
