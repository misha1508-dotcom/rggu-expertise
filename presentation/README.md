# Презентация БИОПРАЙМ

3 вертикальные страницы A4 → `bioprime.pdf`. Формат — «глянуть за минуту»:
крупные фото, один заголовок и три числа на страницу.

1. **Продукт** — пачка 6 × 250 мл за 1250 ₽, доза L. reuteri 1×10⁶ КОЕ, маржа 75 %, график спроса.
2. **Точка продаж** — нарисованная модель холодильника + 3 реальные фотографии,
   выдача в 3 шага, 675 тыс. ₽ выручки и 447 тыс. ₽ прибыли с точки в месяц.
3. **Масштаб** — карта Москвы на 50 точек, 20–25 млн ₽/мес, оценка 1 млрд ₽.

## Пересборка

```bash
python3 build.py     # bioprime.html + bioprime.pdf (headless Chromium)
```

Цифры правятся прямо в HTML-шаблоне внутри `build.py`, динамика спроса — в `TREND_WORLD` / `TREND_RU`.
Шрифт Manrope лежит в `fonts/`, фотографии — в `assets/`.
